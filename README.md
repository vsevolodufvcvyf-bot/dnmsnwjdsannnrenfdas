# nnanserShop

Панель продавца FunPay на базе [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) (автор ядра — @sidor0912)
с набором своих плагинов: выдача звёзд, подарков и SMM через свои API-панели, аренда Steam с кодами Guard,
автоцена, кошелёк и вывод, возвраты за плохие отзывы, ИИ-помощник в чате и инструменты продавца.

Пошаговый запуск — в файле `КАК_ЗАПУСТИТЬ.txt`, список изменений — в `ЧТО_ИЗМЕНЕНО.md`.

## Быстрый старт (Windows)

1. Поставь Python 3.11 или новее с python.org (галочка «Add Python to PATH»).
2. Распакуй папку.
3. Есть старая версия бота — запусти `Migrate.bat`: он перенесёт ключи, настройки, maFile и базу.
   Старую папку он не меняет.
4. Нет `.env` — скопируй `.env.example` в `.env` и впиши свой Telegram ID в `TELEGRAM_OWNER_ID`
   (узнать у @userinfobot).
5. Запусти `Start.bat`. Без старой папки бот на первом запуске спросит golden_key, токен Telegram-бота
   и пароль от пульта.
6. Напиши боту в Telegram `/menu`.

## Что где лежит

| Папка или файл | Что это |
|---|---|
| `configs/` | настройки; недостающие копируются из `configs.example` при запуске |
| `configs/_main.cfg` | golden_key FunPay и токен Telegram-бота — **секреты** |
| `.env` | ID владельца и операторов, ключи нейросетей — **секреты** |
| `mafiles/` | `.maFile` аккаунтов для аренды Steam — **секреты** |
| `storage/` | база (аренды, журнал продаж, решения по возвратам) и бэкапы — личные данные |
| `logs/` | логи; ключи и токены в них маскируются |
| `plugins/` | плагины магазина |
| `playerok-desk/` | своё расширение Chrome для Playerok: автовыдача, аренда Steam, перевыставление |
| `shop_core/` | общий код плагинов |
| `tests/` | автотесты |

## Безопасность

- `configs/`, `.env`, `mafiles/`, `storage/` никому не отправляй и не выкладывай. Они исключены из git и из Docker-образа.
- Пульт открывается владельцу (`TELEGRAM_OWNER_ID`) и операторам по числовому Telegram ID.
  `/op @ник` — только приглашение: когда человек напишет боту, владелец подтверждает кнопкой.
- Вывод денег и возвраты подтверждает владелец. Если панель поставщика ответила неоднозначно,
  повторной закупки не будет, пока продавец не проверит заказ.

## Команды

`/menu` пульт · `/day` отчёт за сегодня · `/goal 3000` цель по чистым · `/hours` когда покупают ·
`/lottext` черновик текста лота · `/orders` заказы в работе · `/stuck` неподтверждённые заказы ·
`/calc` калькулятор · `/export` продажи в CSV · `/lots_backup` бэкап лотов · `/rentpass` пароль слота аренды ·
`/team`, `/op` команда · `/check` проверка · `/panic`, `/unpanic` аварийный стоп · `/dryrun` учебный режим ·
`/margin` запас к закупке · `/balances`, `/withdraw` кошелёк · `/aprice` автоцена · `/stars`, `/gifts` · `/logs`

## Для разработки

```bash
pip install -r requirements-dev.txt
python -m pytest
```

`install-fpc.sh` и `FunPayCardinal@.service` — от оригинального Cardinal для Linux: скрипт ставит оригинал,
а не эту сборку. Автообновление ядра выключено, чтобы не затереть плагины; правки оригинала
(например, под новую вёрстку FunPay) переносятся вручную.
