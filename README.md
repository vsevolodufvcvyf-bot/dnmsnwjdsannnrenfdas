# nnanserShop

Панель продавца FunPay. Запуск: `Start.bat`

В Telegram напиши `/menu`.

| Кнопка | Что делает |
|---|---|
| 📈 Цена | Опиши товар — бот найдёт похожие лоты и скажет цену |
| 📦 Склад | Сколько товара. Если кончился — закупка у поставщика |
| 🛑 Стоп | Гасит закупки и выдачу |
| 📂 Ещё | Автовыдача, автоответ, автоподнятие |

Банк к боту не подключается. Кошелёк — баланс FunPay + API поставщика в `configs/suppliers.cfg`.

Логи: `logs/error.txt`, `logs/bot.txt`, `logs/log.log`
