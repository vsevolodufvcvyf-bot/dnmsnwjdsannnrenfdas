## Этот заход

- Мастер «Шаги: куда заходить» для Steam-панели, Robux Game Pass и файлов с кодами.
- Покупателю Steam и Robux бот задаёт точный вопрос (логин / ник), а не общую фразу.
- Цена ниже пола не считается допустимой. Ключ в таблицу мастера не пишется.
- Автовыдачу FunPay и публикацию лота мастер не включает.

## Не сделано в этом заходе

- Полный каталог «добавить любой товар» с фото и публикацией лота через API FunPay. Создание лота в коде не подтверждено как безопасный общий сценарий: бот не публикует лот сам.
- Общая витрина всех категорий вместо текущих плагинов. Склады не дублировались новой базой: остаётся SQLite `cardinal_storage.db`.
- Режим «ИИ предлагает ответ, продавец подтверждает» как отдельный тумблер поверх текущего автоответа.
- Календарь аренды Dota 2 с MMR. Сейчас есть аренда Steam-слотов, не каталог Dota.
- PostgreSQL не подключался: текущий контур рассчитан на один процесс и SQLite WAL.

## Как проверить

```bash
python3 -m pytest
```

В Telegram: `/methods` → Robux или Steam → «Шаги: куда заходить».
