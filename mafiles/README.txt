Сюда кладутся .maFile от Steam Desktop Authenticator (по одному на аккаунт аренды).
Бот сам заведёт по ним слоты аренды. Пароль от аккаунта задаётся командой в Telegram:
/rentpass <id_слота> <пароль>

В .maFile лежат секреты аутентификатора и токены входа Steam.
Папка исключена из git и из архивов — никому её не отправляй.
